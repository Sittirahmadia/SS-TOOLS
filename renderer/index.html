Detects known cheat client log signatures, module toggle patterns, and suspicious mod loading events.

Process Scanner

Scan running processes and task manager for hidden cheat tools

Scans all running processes including command lines and executable paths. Detects hidden macro tools (198macro, zenithmacro), injectors, AutoHotkey, and cheat clients.

Deleted File Scanner

Detect previously deleted cheat files — even if removed before opening this app

  • PowerShell command history
