Mod Scanner

Scan .jar and .zip mod files for cheat keywords and suspicious content

Supported formats: .jar, .zip, .litemod

Inspects mod archives for cheat-related keywords in class files, configs, and metadata.

JAR Deep Scanner

Deep bytecode analysis of .jar files -- decompile .class files, detect obfuscated cheats, packet manipulation, kill-aura patterns

Deep Analysis: Parses Java bytecode constant pools, identifies cheat class patterns, detects vanilla class modifications, and scans for obfuscated cheat strings.

Targets: mods/, versions/, libraries/, shaderpacks/, resourcepacks/, coremods/

Log Scanner

Scan Minecraft log files for cheat client indicators

Detects known cheat client log signatures, module toggle patterns, and suspicious mod loading events.

Process Scanner

Scan running processes for hidden cheat tools, macros, and injectors

Scans all running processes including command lines and executable paths. Detects: 198Macro, ZenithMacro, AutoHotkey, Cheat Engine, injectors, debuggers, and cheat clients.

DLL Scanner

Enumerate loaded DLLs across all processes -- detect cheat DLLs by name, hash, and strings

Enumerates all loaded DLLs per process. Uses name matching, SHA-256 hashing, and binary string analysis to detect cheat injections, hook libraries, and macro DLLs.

Mouse Software Scanner

Detect and scan gaming mouse software for suspicious macros

Detects: Logitech G HUB, Razer Synapse, Bloody, Redragon, Corsair iCUE, SteelSeries GG, Glorious Core, ROCCAT Swarm

Scans macro profiles for rapid-click, auto-click, jitter-click, and PvP combo macros. Bloody mice are auto-flagged due to hardware-level macro capabilities.

Browser Scanner

Scan browsers for cheat download history, extensions, and bookmarks

Scans: Chrome, Edge, Firefox, Brave

Checks download history for cheat/macro files, browser extensions for auto-clickers, and bookmarks for cheat websites.

Kernel Driver Scanner

Full kernel-mode driver scan -- detect unsigned drivers, exploit drivers, and hidden processes

Requires admin for full scan.

Uses driverquery, fltmc, and file system scanning. Detects Cheat Engine kernel drivers, KDMapper, exploit drivers (capcom.sys, iqvw64e.sys), input injection drivers, and hidden processes.

Deleted File Scanner

Detect previously deleted cheat files -- even if removed before opening this app

Scans multiple sources:

  • Windows Recycle Bin
  • NTFS USN Journal (requires admin)
  • Windows Prefetch (previously run programs)
  • Recent Files history
  • PowerShell command history

String Scanner

Extracts and analyzes ASCII and UTF-16LE strings from binary files. Detects DLL injection patterns, cheat references, and memory manipulation functions.

Launcher Detection

Detect installed Minecraft launchers and their data directories
